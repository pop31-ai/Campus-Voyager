# Campus Voyager

3D-игра про университет на архипелаге островов с кораблём.

## Жанр
3D open-world RPG с морским симулятором

## Управление
- **WASD / Стрелки** — движение корабля
- **Пробел** — буст (ускорение)
- **F** — посетить остров
- **R** — сброс позиции корабля
- **Q** — список квестов
- **ESC** — пауза

## Запуск в Unity

1. Откройте Unity Hub
2. Нажмите "Open" → выберите папку `campus-voyager`
3. Дождитесь импорта проекта
4. Откройте сцену или создайте новую
5. Создайте пустой GameObject, добавьте компонент `SceneSetup`
6. Нажмите Play

## Архитектура

| Скрипт | Описание |
|--------|----------|
| `SceneSetup.cs` | Инициализация камеры и GameManager |
| `GameManager.cs` | Управление игрой, статистика, состояние |
| `ShipController.cs` | Физика и управление кораблём |
| `CameraFollow.cs` | Камера следует за кораблём |
| `IslandGenerator.cs` | Генерация островов с деревьями и дорожками |
| `BuildingGenerator.cs` | Здания университета (4 стиля) |
| `WaterPlane.cs` | Анимированная вода с волнами |
| `ShipWake.cs` | След корабля на воде |
| `QuestSystem.cs` | 6 квестов между факультетами |
| `UIController.cs` | HUD, меню, уведомления |

## Факультеты (острова)

4. Факультет Искусств (жёлтый)
5. Инженерный Факультет (фиолетовый)
